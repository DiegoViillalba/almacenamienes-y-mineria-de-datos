# Instrucciones para agentes en `lectures/`

Si la tarea crea, modifica, recompila o publica una presentación con
**Manim Slides**, lee primero y sigue completamente
[`MANIM-SLIDES.md`](MANIM-SLIDES.md).

La guía define la estructura de carpetas, identidad UNAM, entorno reproducible,
patrones pedagógicos, comandos de renderizado y criterios de aceptación para
las presentaciones animadas de este curso.

Para presentaciones Quarto/Reveal.js que no usen Manim, sigue las convenciones
generales de [`README.md`](README.md) y de `_quarto.yml`.

Conserva siempre los cambios preexistentes del usuario y revisa el diff antes
de entregar.
