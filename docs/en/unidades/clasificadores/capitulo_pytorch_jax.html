This chapter translates neural network concepts into production frameworks:

  • scikit-learn — MLPClassifier with standard fit/predict interface (Pedregosa et al. 2011).
  • PyTorch — Dynamic computational graphs and object-oriented automatic differentiation (Paszke et al. 2019).
  • JAX — Pure functional paradigm with explicit PRNG, vectorization, and XLA compilation (Bradbury et al. 2018; Heek et al. 2023; DeepMind et al. 2020).

2.1 Tensors and Autograd

\[ \frac{\partial \mathcal{L}}{\partial \theta} \quad \forall \theta \text{ with } \texttt{requires\_grad=True} \tag{1}\]

loss.backward() computes gradients automatically via chain rule backpropagation across dynamic computation graphs.

model.train() — Activates training mode for Dropout/BatchNorm.

optimizer.zero_grad() — Clears accumulated gradients before backward pass.

logits = model(X_train) — Executes forward pass computation graph.

loss.backward() — Computes gradients via autograd reverse graph traversal.

optimizer.step() — Applies weight updates using computed gradients.

3 JAX Fundamentals

JAX relies on pure functions and stateless pytrees.

Mutable object-oriented model encapsulation holding parameters internally.

Stateless pure functions receiving parameters externally as explicit pytree dictionaries.

Single-instance scalar Binary Cross Entropy in JAX:

\[ \mathcal{L}(w) = -\left[ y \log \sigma(wx) + (1-y) \log(1 - \sigma(wx)) \right] \tag{3}\]

import jax
import jax.numpy as jnp
import optax

def loss_fn(params, x, y):
    logits = forward(params, x)
    return optax.sigmoid_binary_cross_entropy(logits, y).mean()

@jax.jit
def train_step(params, opt_state, x, y):
    loss, grads = jax.value_and_grad(loss_fn)(params, x, y)
    updates, new_opt_state = optimizer.update(grads, opt_state, params)
    new_params = optax.apply_updates(params, updates)
    return new_params, new_opt_state, loss

4 Summary

PyTorch provides an intuitive, object-oriented imperative workflow ideal for rapid prototyping and debugging. JAX enforces pure functional programming, enabling high-order automatic differentiation and JIT compilation via XLA (Paszke et al. 2019; Bradbury et al. 2018).
