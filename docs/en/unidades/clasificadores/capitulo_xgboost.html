XGBoost (eXtreme Gradient Boosting) was introduced by Chen and Guestrin in 2016 (Chen and Guestrin 2016) and has since dominated machine learning competitions on Kaggle and benchmark platforms. It is a regularized, second-order optimized implementation of the gradient boosting algorithm (Friedman 2001), incorporating key innovations in approximate split finding, efficient sparse data handling, and system-level scalability. This chapter covers the mathematical foundations of the algorithm, its primary hyperparameters, variable importance interpretation using SHAP, and practical implementation in Python.

1 From Decision Trees to Boosting

1.1 The Bias–Variance Trade-off and Individual Trees

A deep decision tree has the capacity to memorize training data: as depth increases, the model fits observed data ever more closely and its variance increases. Conversely, a shallow tree (or single-level decision stump) exhibits high bias due to limited expressive capacity. This bias–variance trade-off is central to machine learning and motivates ensemble learning.

Ensemble methods combine multiple weak learners to form a strong predictor. In bagging (e.g., Random Forest (Breiman 2001)), decision trees are trained independently on bootstrap samples, and predictions are averaged to reduce variance. In boosting, the strategy differs: models are constructed sequentially, where each new tree learns from the residual errors of the preceding ensemble, progressively reducing bias.

1.2 Boosting: Sequential Residual Learning

Boosting builds an additive model sequentially. Starting from a constant initial prediction:

\[F_0(\mathbf{x}) = \underset{\gamma}{\mathrm{argmin}} \sum_{i=1}^{n} L(y_i, \gamma) \tag{1}\]

At each iteration \(m = 1, \ldots, M\), negative gradients (pseudo-residuals) of the loss function evaluated at the current ensemble prediction are computed:

\[r_i^{(m)} = -\left[\frac{\partial L(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right]_{F = F_{m-1}} \tag{2}\]

A weak base learner \(h_m\) is fitted to these pseudo-residuals, and the ensemble is updated:

\[F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \cdot h_m(\mathbf{x}) \tag{3}\]

where \(\eta \in (0, 1]\) is the learning rate or shrinkage parameter. For squared error loss \(L(y, F) = \tfrac{1}{2}(y - F)^2\), the negative gradient simplifies to ordinary residuals \(r_i = y_i - F_{m-1}(\mathbf{x}_i)\). Thus, the algorithm iteratively fits ensemble errors: each new tree targets what previous trees failed to explain.

Gradient Boosting (Simplified Overview)

  1. Initialize constant prediction \(F_0(\mathbf{x}) = \bar{y}\) (target mean).
  2. For \(m = 1, \ldots, M\):
    • Compute residuals \(r_i^{(m)} = y_i - F_{m-1}(\mathbf{x}_i)\).
    • Fit weak base learner \(h_m\) to \(\{(\mathbf{x}_i, r_i^{(m)})\}_{i=1}^n\).
    • Update ensemble \(F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \cdot h_m(\mathbf{x})\).
  3. Return final model \(F_M(\mathbf{x})\).

n2 = 60
X2 = np.sort(rng2.uniform(0, 2 * np.pi, n2)).reshape(-1, 1)
y2 = np.sin(X2.flatten()) + rng2.normal(0, 0.3, n2)
X_line = np.linspace(0, 2 * np.pi, 300).reshape(-1, 1)
y_true_line = np.sin(X_line.flatten())


class Stump:
    def fit(self, X, r):
        best_feat, best_thr, best_loss = 0, 0, float("inf")
        for feat in range(X.shape[1]):
            thresholds = np.unique(X[:, feat])
            for thr in thresholds:
                left = r[X[:, feat] <= thr]
                right = r[X[:, feat] > thr]
                if len(left) == 0 or len(right) == 0:
                    continue
                loss = np.sum((left - left.mean()) ** 2) + np.sum((right - right.mean()) ** 2)
                if loss < best_loss:
                    best_loss = loss
                    best_feat, best_thr = feat, thr
                    self.val_left, self.val_right = left.mean(), right.mean()
        self.feat, self.thr = best_feat, best_thr

    def predict(self, X):
        return np.where(X[:, self.feat] <= self.thr, self.val_left, self.val_right)

As seen in Figure 44.2, residual errors (orange diamonds) progressively shrink as trees are added, and prediction curves (blue) converge toward the underlying true function (dashed black).

Learning rate \(\eta\) in Eq. 44.3 acts as a convergence rate controller. Setting \(\eta=1\) aggressively corrects errors at each step, accelerating overfitting risks. Smaller \(\eta\) values require more boosting rounds but yield superior generalization (shrinkage, Friedman (2002)).

Gradient boosting (Eq. 44.2) represents functional gradient descent: updating target functions directly in function space rather than updating parametric weights in Euclidean space (Friedman 2001).

2 XGBoost Optimization Objective

2.1 Additive Model and Regularized Objective

XGBoost builds additive tree models:

\[\hat{y}_i^{(t)} = \sum_{k=1}^{t} f_k(\mathbf{x}_i), \quad f_k \in \mathcal{F} \tag{4}\]

where \(\mathcal{F}\) is the space of regression trees. At round \(t\), tree \(f_t\) is chosen to minimize the regularized objective:

\[\text{Obj}^{(t)} = \sum_{i=1}^{n} l\!\left(y_i,\, \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)\right) + \Omega(f_t) + \text{constant} \tag{5}\]

Regularization penalty \(\Omega\) penalizes leaf counts and weight magnitudes:

\[\Omega(f) = \gamma T + \frac{1}{2}\lambda\|\mathbf{w}\|^2 \tag{6}\]

where \(T\) is the number of terminal leaves in \(f_t\) and \(\mathbf{w}\) denotes leaf weights. Parameter \(\gamma\) controls pruning thresholding while \(\lambda\) imposes L2 weight regularization.

Key Innovation in XGBoost: Unlike classic gradient boosting (Friedman 2001), XGBoost incorporates explicit structural regularization directly into its optimization objective and uses second-order Taylor expansions (hessians) to derive optimal leaf weights analytically.

2.2 Second-Order Taylor Approximation

Applying a second-order Taylor expansion around \(\hat{y}_i^{(t-1)}\):

\[l\!\left(y_i, \hat{y}_i^{(t-1)} + f_t\right) \approx l\!\left(y_i, \hat{y}_i^{(t-1)}\right) + g_i f_t(\mathbf{x}_i) + \frac{1}{2} h_i f_t^2(\mathbf{x}_i) \tag{7}\]

where:

\[g_i = \frac{\partial\, l(y_i, \hat{y}^{(t-1)})}{\partial\, \hat{y}^{(t-1)}} \quad \text{(first-order gradient)} \tag{8}\]

\[h_i = \frac{\partial^2\, l(y_i, \hat{y}^{(t-1)})}{\partial\, (\hat{y}^{(t-1)})^2} \quad \text{(second-order hessian / local curvature)} \tag{9}\]

Removing constant terms yields the simplified objective at step \(t\):

\[\tilde{\text{Obj}}^{(t)} = \sum_{i=1}^{n}\left[g_i f_t(\mathbf{x}_i) + \frac{1}{2}h_i f_t^2(\mathbf{x}_i)\right] + \gamma T + \frac{1}{2}\lambda\sum_{j=1}^{T}w_j^2 \tag{10}\]

This quadratic formulation is exact for squared error loss and provides an effective local quadratic approximation for any twice-differentiable loss function.

2.3 Optimal Leaf Weights

Grouping sample indices by terminal leaf node \(j\) (\(I_j = \{i : q(\mathbf{x}_i) = j\}\)):

\[\tilde{\text{Obj}}^{(t)} = \sum_{j=1}^{T}\left[\left(\sum_{i\in I_j}g_i\right)w_j + \frac{1}{2}\left(\sum_{i\in I_j}h_i + \lambda\right)w_j^2\right] + \gamma T \tag{11}\]

Defining \(G_j = \sum_{i\in I_j} g_i\) and \(H_j = \sum_{i\in I_j} h_i\), solving \(\frac{\partial \tilde{\text{Obj}}}{\partial w_j} = 0\) yields optimal leaf weight \(w_j^*\):

\[w_j^* = -\frac{G_j}{H_j + \lambda} \tag{12}\]

Substituting optimal weights back into the objective yields the structure score:

\[\text{Obj}^* = -\frac{1}{2}\sum_{j=1}^{T}\frac{G_j^2}{H_j + \lambda} + \gamma T \tag{13}\]

2.4 Split Gain Metric

For a node split dividing parent node \(P\) into left (\(L\)) and right (\(R\)) children:

\[\text{Gain} = \frac{1}{2}\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G_P^2}{H_P+\lambda}\right] - \gamma \tag{14}\]

If \(\text{Gain} \le 0\), the candidate split is pruned.

Show code 
import numpy as np
import plotly.graph_objects as go

rng3 = np.random.default_rng(21)
n3 = 150
X3 = np.sort(rng3.uniform(0, 10, n3))
y3 = 2.0 * np.sin(X3 * 0.8) + rng3.normal(0, 0.5, n3)

F_prev = np.full(n3, y3.mean())
g_vals = -(y3 - F_prev)
h_vals = np.ones(n3)

lam3 = 1.0
G_total = g_vals.sum()
H_total = h_vals.sum()
score_parent = G_total ** 2 / (H_total + lam3)

thresholds = np.unique(X3)[1:-1]
gains = []

for thr in thresholds:
    left_mask = X3 <= thr
    right_mask = ~left_mask
    G_L = g_vals[left_mask].sum()
    H_L = h_vals[left_mask].sum()
    G_R = g_vals[right_mask].sum()
    H_R = h_vals[right_mask].sum()
    if H_L + lam3 <= 0 or H_R + lam3 <= 0:
        gains.append(float("nan"))
        continue
    gain = 0.5 * (G_L ** 2 / (H_L + lam3) + G_R ** 2 / (H_R + lam3) - score_parent)
    gains.append(gain)

gains = np.array(gains)
best_idx = np.nanargmax(gains)
best_thr = thresholds[best_idx]
best_gain = gains[best_idx]

fig4 = go.Figure()

fig4.add_trace(go.Scatter(
    x=thresholds, y=gains,
    mode="lines",
    fill="tozeroy",
    fillcolor="rgba(37, 99, 235, 0.15)",
    line=dict(color="#2563eb", width=2.0),
    name="Gain"
))
fig4.add_trace(go.Scatter(
    x=[best_thr, best_thr],
    y=[gains.min() - 0.5, best_gain],
    mode="lines",
    line=dict(color="red", dash="dash", width=2.0),
    name=f"Optimal Threshold = {best_thr:.2f}"

    text=f"Optimal: thr={best_thr:.2f}, Gain={best_gain:.2f}",
    showarrow=True, arrowhead=2,
    font=dict(size=12, color="red")

    template="plotly_white",

2.5 Approximate Split Finding and Sparsity Awareness

For massive datasets, exact greedy split search is computationally prohibitive. XGBoost employs a weighted quantile sketch strategy to propose candidate split points \(\mathcal{S}_k = \{s_{k1}, s_{k2}, \ldots, s_{kl}\}\) based on feature distributions weighted by hessians \(h_i\) (Chen and Guestrin 2016):

\[\text{rank}_k(z) = \frac{\sum_{(x,h): x_k < z} h}{\sum_{(x,h)} h} \tag{15}\]

XGBoost also features native sparsity awareness: it learns default split directions for missing or zero values at each node, bypassing pre-imputation requirements.

4 Variable Importance Metrics

XGBoost evaluates feature importance via three metrics:

  1. Weight (frequency): Relative count of splits on feature \(k\) across all trees.
  2. Gain: Average loss reduction achieved by splits on feature \(k\) (\(\text{Gain}_k = \frac{1}{|\mathcal{T}_k|} \sum_{t \in \mathcal{T}_k} \text{Gain}_t\), ?eq-importancia-gain).
  3. Coverage: Average sample count passing through splits on feature \(k\).

XGBoost (*eXtreme Gradient Boosting*) was introduced by Chen and Guestrin in 2016 [@chen2016xgboost] and has since dominated machine learning competitions on Kaggle and benchmark platforms. It is a regularized, second-order optimized implementation of the gradient boosting algorithm [@friedman2001greedy], incorporating key innovations in approximate split finding, efficient sparse data handling, and system-level scalability. This chapter covers the mathematical foundations of the algorithm, its primary hyperparameters, variable importance interpretation using SHAP, and practical implementation in Python.

## From Decision Trees to Boosting

### The Bias–Variance Trade-off and Individual Trees

A deep decision tree has the capacity to memorize training data: as depth increases, the model fits observed data ever more closely and its variance increases. Conversely, a shallow tree (or single-level decision stump) exhibits high bias due to limited expressive capacity. This bias–variance trade-off is central to machine learning and motivates ensemble learning.

Ensemble methods combine multiple weak learners to form a strong predictor. In *bagging* (e.g., Random Forest [@breiman2001random]), decision trees are trained independently on bootstrap samples, and predictions are averaged to reduce variance. In *boosting*, the strategy differs: models are constructed sequentially, where each new tree learns from the residual errors of the preceding ensemble, progressively reducing bias.

### Boosting: Sequential Residual Learning

Boosting builds an additive model sequentially. Starting from a constant initial prediction:

$$F_0(\mathbf{x}) = \underset{\gamma}{\mathrm{argmin}} \sum_{i=1}^{n} L(y_i, \gamma)$$ {#eq-f0}

At each iteration $m = 1, \ldots, M$, negative gradients (pseudo-residuals) of the loss function evaluated at the current ensemble prediction are computed:

$$r_i^{(m)} = -\left[\frac{\partial L(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right]_{F = F_{m-1}}$$ {#eq-pseudoresiduos}

A weak base learner $h_m$ is fitted to these pseudo-residuals, and the ensemble is updated:

$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \cdot h_m(\mathbf{x})$$ {#eq-actualizacion}

where $\eta \in (0, 1]$ is the learning rate or *shrinkage* parameter. For squared error loss $L(y, F) = \tfrac{1}{2}(y - F)^2$, the negative gradient simplifies to ordinary residuals $r_i = y_i - F_{m-1}(\mathbf{x}_i)$. Thus, the algorithm iteratively fits ensemble errors: each new tree targets what previous trees failed to explain.

::: {.callout-note appearance="minimal"}
**Gradient Boosting (Simplified Overview)**

1. Initialize constant prediction $F_0(\mathbf{x}) = \bar{y}$ (target mean).
2. For $m = 1, \ldots, M$:
   - Compute residuals $r_i^{(m)} = y_i - F_{m-1}(\mathbf{x}_i)$.
   - Fit weak base learner $h_m$ to $\{(\mathbf{x}_i, r_i^{(m)})\}_{i=1}^n$.
   - Update ensemble $F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \eta \cdot h_m(\mathbf{x})$.
3. Return final model $F_M(\mathbf{x})$.
:::

## XGBoost Optimization Objective

### Additive Model and Regularized Objective

XGBoost builds additive tree models:

$$\hat{y}_i^{(t)} = \sum_{k=1}^{t} f_k(\mathbf{x}_i), \quad f_k \in \mathcal{F}$$ {#eq-modelo-aditivo}

where $\mathcal{F}$ is the space of regression trees. At round $t$, tree $f_t$ is chosen to minimize the regularized objective:

$$\text{Obj}^{(t)} = \sum_{i=1}^{n} l\!\left(y_i,\, \hat{y}_i^{(t-1)} + f_t(\mathbf{x}_i)\right) + \Omega(f_t) + \text{constant}$$ {#eq-objetivo}

Regularization penalty $\Omega$ penalizes leaf counts and weight magnitudes:

$$\Omega(f) = \gamma T + \frac{1}{2}\lambda\|\mathbf{w}\|^2$$ {#eq-regularizacion}

where $T$ is the number of terminal leaves in $f_t$ and $\mathbf{w}$ denotes leaf weights. Parameter $\gamma$ controls pruning thresholding while $\lambda$ imposes L2 weight regularization.

::: {.callout-note appearance="minimal"}
**Key Innovation in XGBoost:** Unlike classic gradient boosting [@friedman2001greedy], XGBoost incorporates explicit structural regularization directly into its optimization objective and uses second-order Taylor expansions (hessians) to derive optimal leaf weights analytically.
:::

### Second-Order Taylor Approximation

Applying a second-order Taylor expansion around $\hat{y}_i^{(t-1)}$:

$$l\!\left(y_i, \hat{y}_i^{(t-1)} + f_t\right) \approx l\!\left(y_i, \hat{y}_i^{(t-1)}\right) + g_i f_t(\mathbf{x}_i) + \frac{1}{2} h_i f_t^2(\mathbf{x}_i)$$ {#eq-taylor}

where:

$$g_i = \frac{\partial\, l(y_i, \hat{y}^{(t-1)})}{\partial\, \hat{y}^{(t-1)}} \quad \text{(first-order gradient)}$$ {#eq-gradiente}

$$h_i = \frac{\partial^2\, l(y_i, \hat{y}^{(t-1)})}{\partial\, (\hat{y}^{(t-1)})^2} \quad \text{(second-order hessian / local curvature)}$$ {#eq-hessiano}

Removing constant terms yields the simplified objective at step $t$:

$$\tilde{\text{Obj}}^{(t)} = \sum_{i=1}^{n}\left[g_i f_t(\mathbf{x}_i) + \frac{1}{2}h_i f_t^2(\mathbf{x}_i)\right] + \gamma T + \frac{1}{2}\lambda\sum_{j=1}^{T}w_j^2$$ {#eq-objetivo-simplificado}

This quadratic formulation is exact for squared error loss and provides an effective local quadratic approximation for any twice-differentiable loss function.

### Optimal Leaf Weights

Grouping sample indices by terminal leaf node $j$ ($I_j = \{i : q(\mathbf{x}_i) = j\}$):

$$\tilde{\text{Obj}}^{(t)} = \sum_{j=1}^{T}\left[\left(\sum_{i\in I_j}g_i\right)w_j + \frac{1}{2}\left(\sum_{i\in I_j}h_i + \lambda\right)w_j^2\right] + \gamma T$$ {#eq-objetivo-hojas}

Defining $G_j = \sum_{i\in I_j} g_i$ and $H_j = \sum_{i\in I_j} h_i$, solving $\frac{\partial \tilde{\text{Obj}}}{\partial w_j} = 0$ yields optimal leaf weight $w_j^*$:

$$w_j^* = -\frac{G_j}{H_j + \lambda}$$ {#eq-peso-optimo}

Substituting optimal weights back into the objective yields the structure score:

$$\text{Obj}^* = -\frac{1}{2}\sum_{j=1}^{T}\frac{G_j^2}{H_j + \lambda} + \gamma T$$ {#eq-objetivo-optimo}

### Split Gain Metric

For a node split dividing parent node $P$ into left ($L$) and right ($R$) children:

$$\text{Gain} = \frac{1}{2}\left[\frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{G_P^2}{H_P+\lambda}\right] - \gamma$$ {#eq-ganancia}

If $\text{Gain} \le 0$, the candidate split is pruned.

```{python}
#| label: fig-xgb-ganancia
#| fig-cap: "Split gain as a function of cut threshold for a synthetic 1D dataset. Dashed red line indicates optimal split threshold (maximum gain). Dashed gray line indicates Gain=0 pruning threshold when gamma=0."
#| code-fold: true

import numpy as np
import plotly.graph_objects as go

rng3 = np.random.default_rng(21)
n3 = 150
X3 = np.sort(rng3.uniform(0, 10, n3))
y3 = 2.0 * np.sin(X3 * 0.8) + rng3.normal(0, 0.5, n3)

F_prev = np.full(n3, y3.mean())
g_vals = -(y3 - F_prev)
h_vals = np.ones(n3)

lam3 = 1.0
G_total = g_vals.sum()
H_total = h_vals.sum()
score_parent = G_total ** 2 / (H_total + lam3)

thresholds = np.unique(X3)[1:-1]
gains = []

for thr in thresholds:
    left_mask = X3 <= thr
    right_mask = ~left_mask
    G_L = g_vals[left_mask].sum()
    H_L = h_vals[left_mask].sum()
    G_R = g_vals[right_mask].sum()
    H_R = h_vals[right_mask].sum()
    if H_L + lam3 <= 0 or H_R + lam3 <= 0:
        gains.append(float("nan"))
        continue
    gain = 0.5 * (G_L ** 2 / (H_L + lam3) + G_R ** 2 / (H_R + lam3) - score_parent)
    gains.append(gain)

gains = np.array(gains)
best_idx = np.nanargmax(gains)
best_thr = thresholds[best_idx]
best_gain = gains[best_idx]

fig4 = go.Figure()

fig4.add_trace(go.Scatter(
    x=thresholds, y=gains,
    mode="lines",
    fill="tozeroy",
    fillcolor="rgba(37, 99, 235, 0.15)",
    line=dict(color="#2563eb", width=2.0),
    name="Gain"
))
fig4.add_trace(go.Scatter(
    x=[best_thr, best_thr],
    y=[gains.min() - 0.5, best_gain],
    mode="lines",
    line=dict(color="red", dash="dash", width=2.0),
    name=f"Optimal Threshold = {best_thr:.2f}"
))
fig4.add_trace(go.Scatter(
    x=[thresholds.min(), thresholds.max()],
    y=[0, 0],
    mode="lines",
    line=dict(color="gray", dash="dash", width=1.5),
    name="Gain = 0 (Pruning)"
))
fig4.add_annotation(
    x=best_thr, y=best_gain + 0.3,
    text=f"Optimal: thr={best_thr:.2f}, Gain={best_gain:.2f}",
    showarrow=True, arrowhead=2,
    font=dict(size=12, color="red")
)
fig4.update_layout(
    template="plotly_white",
    height=400,
    xaxis_title="Split Threshold",
    yaxis_title="Gain",
    legend=dict(orientation="h", yanchor="bottom", y=-0.3, xanchor="center", x=0.5)
)
fig4.show()
```

### Approximate Split Finding and Sparsity Awareness

For massive datasets, exact greedy split search is computationally prohibitive. XGBoost employs a weighted quantile sketch strategy to propose candidate split points $\mathcal{S}_k = \{s_{k1}, s_{k2}, \ldots, s_{kl}\}$ based on feature distributions weighted by hessians $h_i$ [@chen2016xgboost]:

$$\text{rank}_k(z) = \frac{\sum_{(x,h): x_k < z} h}{\sum_{(x,h)} h}$$ {#eq-rank}

XGBoost also features native **sparsity awareness**: it learns default split directions for missing or zero values at each node, bypassing pre-imputation requirements.

## Variable Importance Metrics

XGBoost evaluates feature importance via three metrics:

1. **Weight (frequency):** Relative count of splits on feature $k$ across all trees.
2. **Gain:** Average loss reduction achieved by splits on feature $k$ ($\text{Gain}_k = \frac{1}{|\mathcal{T}_k|} \sum_{t \in \mathcal{T}_k} \text{Gain}_t$, @eq-importancia-gain).
3. **Coverage:** Average sample count passing through splits on feature $k$.

## Feature Contributions (SHAP Values) {#sec-shap}

SHAP values (@lundberg2017unified; @lundberg2020local2global) decompose individual predictions into additive feature contributions:

$$\hat{y}_i = \phi_0 + \sum_{j=1}^{p} \phi_j$$ {#eq-shap}

where $\phi_0 = \mathbb{E}[\hat{y}]$ is baseline expectation and $\phi_j$ is feature $j$'s localized contribution for instance $i$.

```{python}
#| label: fig-xgb-waterfall
#| fig-cap: "Waterfall plot displaying localized feature contributions for a single instance in California Housing. Green bars increase prediction; red bars decrease prediction."
```
