Supervised learning explores problems where input observations are paired with target response labels. Given a training dataset, the objective is learning a mapping function capable of predicting responses for unseen future observations. Formally, training data are structured as:

\[ \mathcal{D}=\{(\mathbf{x}_i,y_i)\}_{i=1}^n, \]

where \(\mathbf{x}_i\in\mathbb{R}^p\) represents a feature vector and \(y_i\) represents the target response. When \(y_i\) is a continuous scalar magnitude, the problem is formulated as regression; when \(y_i\) represents a discrete categorical class, it is formulated as classification (Hastie et al. 2009; bishop2006pattern?).

This chapter explores two central families of deterministic models in supervised learning: linear regression (used for numerical target forecasting) and linear classifiers (used for separating classes using hyperplanes). We first develop simple and multiple linear regression, review evaluation metrics for continuous response models, and present Fisher’s Linear Discriminant and the Perceptron as foundational linear classification algorithms (Goodfellow et al. 2016; vapnik1998statistical?).

1 Regression: Continuous Variable Prediction

In regression problems, the target response variable takes real-valued continuous numbers. Typical examples include house prices, ambient temperatures, monthly income, or patient length of stay. The task consists of learning a mapping function \(f\) such that:

\[ \widehat{y}=f(\mathbf{x}) \]

serves as an accurate prediction of observed target \(y\).

Definition. Supervised regression estimates a mapping function \(f:\mathcal{X}\to\mathbb{R}\) from paired training instances \(\mathcal{D}=\{(\mathbf{x}_i,y_i)\}_{i=1}^n\) such that predicted responses \(\widehat{y}_i=f(\mathbf{x}_i)\) approximate target values \(y_i\): \[ \widehat{y}_i=f(\mathbf{x}_i),\qquad y_i\in\mathbb{R}. \tag{1}\]

Regression can be tackled using models of varying complexity, including linear regression, polynomial regression, decision trees, random forests, and gradient boosted trees (Breiman 2001; Chen and Guestrin 2016). However, linear regression occupies a foundational position due to its analytical solvability, interpretability, and clear coefficient semantics.

1.1 Simple and Multiple Linear Regression

Simple linear regression uses a single predictor feature \(x\):

\[ \widehat{y}=\beta_0+\beta_1 x, \]

where \(\beta_0\) represents the intercept and \(\beta_1\) represents the slope (expected change in \(y\) per unit change in \(x\)).

Multiple linear regression generalizes this formulation to \(p\) predictor variables:

\[ y=\beta_0+\beta_1x_1+\beta_2x_2+\cdots+\beta_px_p+\varepsilon, \]

where \(\varepsilon\) denotes the unobserved zero-mean error term.

Definition. The multiple linear regression model expresses target response \(y_i\) as a linear combination of \(p\) predictor variables plus an error term: \[ y_i=\beta_0+\sum_{j=1}^{p}\beta_jx_{ij}+\varepsilon_i, \qquad i=1,\ldots,n. \tag{2}\]

For example, predicting a student’s final grade using study hours, attendance rate, and submitted assignments:

\[ \widehat{\text{grade}}=20+5(\text{hours})+0.3(\text{attendance})+2(\text{assignments}). \]

Here, \(\beta_1 = 5\) suggests that each additional study hour is associated with an expected 5-point increase in final grade, holding attendance and assignment counts constant.

2 Matrix Representation of Linear Regression

Matrix notation simplifies multiple linear regression mechanics:

\[ \mathbf{y}=\begin{bmatrix}y_1\\y_2\\\vdots\\y_n\end{bmatrix}, \qquad \mathbf{X}=\begin{bmatrix} 1 & x_{11} & x_{12} & \cdots & x_{1p}\\ 1 & x_{21} & x_{22} & \cdots & x_{2p}\\ \vdots & \vdots & \vdots & \ddots & \vdots\\ 1 & x_{n1} & x_{n2} & \cdots & x_{np} \end{bmatrix}, \qquad \boldsymbol{\beta}=\begin{bmatrix}\beta_0\\\beta_1\\\vdots\\\beta_p\end{bmatrix}. \]

Definition. Design matrix \(\mathbf{X}\in\mathbb{R}^{n\times(p+1)}\) contains one row per sample and one column per feature, plus a leading bias column of ones: \[ \mathbf{y}=\mathbf{X}\boldsymbol{\beta}+\boldsymbol{\varepsilon}. \tag{3}\]

Ordinary Least Squares (OLS) minimizes Sum of Squared Errors (SSE) (legendre1805nouvelles?; gauss1809theoria?):

\[ \min_{\boldsymbol{\beta}}\;\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2. \]

If \(\mathbf{X}^\top\mathbf{X}\) is non-singular (full column rank), the closed-form analytical OLS solution is:

\[ \widehat{\boldsymbol{\beta}}=(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}. \tag{4}\]

Predicted target responses and residual vectors are computed as:

\[ \widehat{\mathbf{y}}=\mathbf{X}\widehat{\boldsymbol{\beta}}, \qquad \widehat{\boldsymbol{\varepsilon}}=\mathbf{y}-\widehat{\mathbf{y}}. \]

2.1 Invertibility and Multicollinearity

Analytical OLS requires \(\mathbf{X}^\top\mathbf{X}\) to be non-singular. If features are collinear, column vectors become linearly dependent, leading to rank deficiency. High multicollinearity produces large coefficient variance (hoerl1970ridge?; golub2013matrix?).

4 Regression Evaluation Metrics

Definition. Sum of Squared Errors (SSE) measures cumulative squared residual discrepancies: \[ \mathrm{SSE}=\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2. \tag{5}\]

  • Mean Squared Error (MSE): \(\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2\)
  • Root Mean Squared Error (RMSE): \(\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2}\)
  • Mean Absolute Error (MAE): \(\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\widehat{y}_i|\) {#eq-mae}
  • Coefficient of Determination (\(R^2\)): \(R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}}\) {#eq-r2}

5 Linear Classifiers

Binary linear classifiers assign labels based on the sign of an affine discriminant function:

\[ g(\mathbf{x})=\mathbf{w}^\top\mathbf{x}+w_0. \]

Definition. A binary linear classifier assigns class labels via: \[ \widehat{y}=\operatorname{sign}(\mathbf{w}^\top\mathbf{x}+w_0), \qquad \widehat{y}\in\{-1,+1\}. \tag{6}\]

6 Fisher’s Linear Discriminant

Fisher’s Linear Discriminant finds a projection vector \(\mathbf{w}\) maximizing between-class variance relative to within-class variance (fisher1936use?).

Definition. Fisher’s criterion maximizes class mean separation relative to within-class scatter: \[ J_F(\mathbf{w})=\frac{\mathbf{w}^\top\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}. \tag{7}\]

The optimal projection vector is:

\[ \mathbf{w}^*\propto \mathbf{S}_W^{-1}(\mathbf{m}_1-\mathbf{m}_2). \]

7 The Perceptron

Rosenblatt’s Perceptron (rosenblatt1958perceptron?) learns decision weights iteratively from classification errors.

Definition. The Perceptron error-driven update rule adjusts parameter weights upon misclassifying instance \(i\): \[ \mathbf{w}^{(t+1)}=\mathbf{w}^{(t)}+\eta y_i\mathbf{x}_i, \qquad b^{(t+1)}=b^{(t)}+\eta y_i. \tag{8}\]

Novikoff’s Perceptron Convergence Theorem guarantees convergence in finite update steps if data are linearly separable (novikoff1962convergence?; minsky1969perceptrons?).

Definition. Dataset \(\mathcal{D}\) is linearly separable if there exists weight vector \(\mathbf{w}\) and bias \(b\) satisfying: \[ y_i(\mathbf{w}^\top\mathbf{x}_i+b)>0, \qquad i=1,\ldots,n. \tag{9}\]

import numpy as np

class PerceptronBinario:
    def __init__(self, lr=1.0, max_epochs=100):
        self.lr = lr
        self.max_epochs = max_epochs
        self.w = None
        self.b = 0.0
        self.errors_ = []

    def fit(self, X, y):
        X = np.asarray(X, dtype=float)
        y = np.asarray(y, dtype=float)
        self.w = np.zeros(X.shape[1])
        self.b = 0.0

        for _ in range(self.max_epochs):
            errores = 0
            for xi, yi in zip(X, y):
                if yi * (np.dot(self.w, xi) + self.b) <= 0:
                    self.w += self.lr * yi * xi
                    self.b += self.lr * yi
                    errores += 1
            self.errors_.append(errores)
            if errores == 0:
                break
        return self

    def decision_function(self, X):
        return np.asarray(X) @ self.w + self.b

    def predict(self, X):
        return np.where(self.decision_function(X) >= 0, 1, -1)

9 Conclusions

Linear regression and linear classifiers serve as fundamental building blocks of supervised machine learning. Linear regression models continuous responses via analytical OLS estimation. Fisher’s Discriminant demonstrates optimal linear subspace projections. The Perceptron illustrates error-driven online weight updates. Understanding these foundational models prepares practitioners for advanced non-linear techniques, regularization frameworks, and deep learning architectures.

## Matrix Representation of Linear Regression

Matrix notation simplifies multiple linear regression mechanics:

$$
\mathbf{y}=\begin{bmatrix}y_1\\y_2\\\vdots\\y_n\end{bmatrix},
\qquad
\mathbf{X}=\begin{bmatrix}
1 & x_{11} & x_{12} & \cdots & x_{1p}\\
1 & x_{21} & x_{22} & \cdots & x_{2p}\\
\vdots & \vdots & \vdots & \ddots & \vdots\\
1 & x_{n1} & x_{n2} & \cdots & x_{np}
\end{bmatrix},
\qquad
\boldsymbol{\beta}=\begin{bmatrix}\beta_0\\\beta_1\\\vdots\\\beta_p\end{bmatrix}.
$$

::: {.callout-note appearance="minimal"}
Definition. Design matrix $\mathbf{X}\in\mathbb{R}^{n\times(p+1)}$ contains one row per sample and one column per feature, plus a leading bias column of ones:
$$
\mathbf{y}=\mathbf{X}\boldsymbol{\beta}+\boldsymbol{\varepsilon}.
$$ {#eq-matrix-linear-model}
:::

Ordinary Least Squares (OLS) minimizes Sum of Squared Errors (SSE) [@legendre1805nouvelles; @gauss1809theoria]:

$$
\min_{\boldsymbol{\beta}}\;\|\mathbf{y}-\mathbf{X}\boldsymbol{\beta}\|_2^2.
$$

If $\mathbf{X}^\top\mathbf{X}$ is non-singular (full column rank), the closed-form analytical OLS solution is:

$$
\widehat{\boldsymbol{\beta}}=(\mathbf{X}^\top\mathbf{X})^{-1}\mathbf{X}^\top\mathbf{y}.
$$ {#eq-ols-definition}

Predicted target responses and residual vectors are computed as:

$$
\widehat{\mathbf{y}}=\mathbf{X}\widehat{\boldsymbol{\beta}},
\qquad
\widehat{\boldsymbol{\varepsilon}}=\mathbf{y}-\widehat{\mathbf{y}}.
$$

### Invertibility and Multicollinearity

Analytical OLS requires $\mathbf{X}^\top\mathbf{X}$ to be non-singular. If features are collinear, column vectors become linearly dependent, leading to rank deficiency. High multicollinearity produces large coefficient variance [@hoerl1970ridge; @golub2013matrix].

## Regression Evaluation Metrics

::: {.callout-note appearance="minimal"}
Definition. Sum of Squared Errors (SSE) measures cumulative squared residual discrepancies:
$$
\mathrm{SSE}=\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2.
$$ {#eq-sse}
:::

- **Mean Squared Error (MSE):** $\mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2$
- **Root Mean Squared Error (RMSE):** $\mathrm{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\widehat{y}_i)^2}$
- **Mean Absolute Error (MAE):** $\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}|y_i-\widehat{y}_i|$ {#eq-mae}
- **Coefficient of Determination ($R^2$):** $R^2=1-\frac{\mathrm{SSE}}{\mathrm{SST}}$ {#eq-r2}

## Fisher's Linear Discriminant

Fisher's Linear Discriminant finds a projection vector $\mathbf{w}$ maximizing between-class variance relative to within-class variance [@fisher1936use].

::: {.callout-note appearance="minimal"}
Definition. Fisher's criterion maximizes class mean separation relative to within-class scatter:
$$
J_F(\mathbf{w})=\frac{\mathbf{w}^\top\mathbf{S}_B\mathbf{w}}{\mathbf{w}^\top\mathbf{S}_W\mathbf{w}}.
$$ {#eq-fisher-criterion}
:::

The optimal projection vector is:

$$
\mathbf{w}^*\propto \mathbf{S}_W^{-1}(\mathbf{m}_1-\mathbf{m}_2).
$$

## The Perceptron

Rosenblatt's Perceptron [@rosenblatt1958perceptron] learns decision weights iteratively from classification errors.

::: {.callout-note appearance="minimal"}
Definition. The Perceptron error-driven update rule adjusts parameter weights upon misclassifying instance $i$:
$$
\mathbf{w}^{(t+1)}=\mathbf{w}^{(t)}+\eta y_i\mathbf{x}_i,
\qquad
b^{(t+1)}=b^{(t)}+\eta y_i.
$$ {#eq-perceptron-update}
:::

Novikoff's Perceptron Convergence Theorem guarantees convergence in finite update steps if data are linearly separable [@novikoff1962convergence; @minsky1969perceptrons].

::: {.callout-note appearance="minimal"}
Definition. Dataset $\mathcal{D}$ is linearly separable if there exists weight vector $\mathbf{w}$ and bias $b$ satisfying:
$$
y_i(\mathbf{w}^\top\mathbf{x}_i+b)>0,
\qquad i=1,\ldots,n.
$$ {#eq-linear-separability}
:::

```{=html}
    if(i+1>=N&&ptr<=i) epochN++;
```

```python
import numpy as np

class PerceptronBinario:
    def __init__(self, lr=1.0, max_epochs=100):
        self.lr = lr
        self.max_epochs = max_epochs
        self.w = None
        self.b = 0.0
        self.errors_ = []

    def fit(self, X, y):
        X = np.asarray(X, dtype=float)
        y = np.asarray(y, dtype=float)
        self.w = np.zeros(X.shape[1])
        self.b = 0.0

        for _ in range(self.max_epochs):
            errores = 0
            for xi, yi in zip(X, y):
                if yi * (np.dot(self.w, xi) + self.b) <= 0:
                    self.w += self.lr * yi * xi
                    self.b += self.lr * yi
                    errores += 1
            self.errors_.append(errores)
            if errores == 0:
                break
        return self

    def decision_function(self, X):
        return np.asarray(X) @ self.w + self.b

    def predict(self, X):
        return np.where(self.decision_function(X) >= 0, 1, -1)
```
