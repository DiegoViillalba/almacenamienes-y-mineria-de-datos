53  Introduction to Clustering and Evaluation Metrics

  • Show All Code
  • Hide All Code
  • View Source
Author

Diego Villalba

Published

August 5, 2026

Supervised learning derives mappings from labeled instances to generalize predictions onto unseen data. Unsupervised learning operates on unlabeled data to discover underlying structure: grouping similar instances, uncovering latent factors, or constructing low-dimensional representations (Hastie et al. 2009; Bishop 2006).

Clustering is the primary unsupervised learning task. Given observations \(\mathbf{x}_1,\dots,\mathbf{x}_n\in\mathbb{R}^p\), the objective is partitioning them into clusters \(C_1,\dots,C_k\) such that within-cluster similarity is maximized relative to between-cluster separation (Aggarwal and Reddy 2013).

1 The Clustering Problem

Let \(\mathcal{D}=\{\mathbf{x}_1,\dots,\mathbf{x}_n\}\) denote \(n\) instances in \(\mathbb{R}^p\). A \(k\)-cluster assignment is defined by mapping:

\[ \ell:\{1,\dots,n\}\to\{1,\dots,k\}, \]

where cluster \(C_j\) contains instances assigned to label \(j\):

\[ C_j=\{\mathbf{x}_i\mid \ell(i)=j\}. \]

2 Distance and Similarity Measures

Definition. Metric Function Properties: 1. \(d(\mathbf{x},\mathbf{y})\geq 0\) and \(d(\mathbf{x},\mathbf{y})=0\Leftrightarrow\mathbf{x}=\mathbf{y}\) (positive definiteness), 2. \(d(\mathbf{x},\mathbf{y})=d(\mathbf{y},\mathbf{x})\) (symmetry), 3. \(d(\mathbf{x},\mathbf{z})\leq d(\mathbf{x},\mathbf{y})+d(\mathbf{y},\mathbf{z})\) (triangle inequality).

2.1 Minkowski Distance Family

Definition. Minkowski Distance of order \(p\ge 1\): \[ d_p(\mathbf{x},\mathbf{y}) = \left(\sum_{j=1}^{d}|x_j-y_j|^p\right)^{1/p}. \tag{1}\]

  • \(p=1\): Manhattan (\(L^1\)) distance.
  • \(p=2\): Euclidean (\(L^2\)) distance.
  • \(p\to\infty\): Chebyshev (\(L^\infty\)) distance.

3 Internal Evaluation Metrics

3.1 Silhouette Coefficient

Definition. Silhouette Coefficient \(s(i)\): \[ s(i) = \frac{b(i)-a(i)}{\max\{a(i),b(i)\}}. \tag{2}\]

where \(a(i)\) is mean intra-cluster distance, and \(b(i)\) is mean nearest-cluster distance (Rousseeuw 1987).

3.2 Davies-Bouldin Index

Definition. Davies-Bouldin Index: \[ \text{DB} = \frac{1}{K}\sum_{k=1}^{K}\max_{l\neq k}\frac{\bar{d}_k+\bar{d}_l}{d(k,l)}. \tag{3}\]

Lower DB values indicate superior cluster compactness and separation (Davies and Bouldin 1979).

3.3 Calinski-Harabasz Index

Definition. Calinski-Harabasz Index: \[ \text{CH} = \frac{\text{SS}_B/(K-1)}{\text{SS}_W/(n-K)}. \tag{4}\]

Higher CH values denote distinct, dense cluster separations (Caliński and Harabasz 1974).

Show code 
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score, calinski_harabasz_score

X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

for k in range(2, 6):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X)
    s = silhouette_score(X, labels)
    db = davies_bouldin_score(X, labels)
    ch = calinski_harabasz_score(X, labels)
    print(f"k={k} | Silhouette: {s:.3f} | Davies-Bouldin: {db:.3f} | Calinski-Harabasz: {ch:.1f}")

4 External Evaluation Metrics

4.1 Adjusted Rand Index (ARI)

Definition. Adjusted Rand Index: \[ \text{ARI} = \frac{\text{RI} - \mathbb{E}[\text{RI}]}{\max(\text{RI}) - \mathbb{E}[\text{RI}]}. \tag{5}\]

ARI measures pair agreement against ground-truth partition, adjusted for chance (Hubert and Arabie 1985).

5 Summary

Unsupervised clustering organizes unlabeled data using geometric or probabilistic distance metrics. Internal evaluation metrics (Silhouette, Davies-Bouldin, Calinski-Harabasz) validate cluster quality without ground-truth labels, while external metrics (ARI, NMI) measure agreement against reference partitions.

## Internal Evaluation Metrics

### Silhouette Coefficient

::: {.callout-note appearance="minimal"}
Definition. Silhouette Coefficient $s(i)$:
$$
s(i) = \frac{b(i)-a(i)}{\max\{a(i),b(i)\}}.
$$ {#eq-silhouette}
:::

where $a(i)$ is mean intra-cluster distance, and $b(i)$ is mean nearest-cluster distance [@rousseeuw1987].

### Davies-Bouldin Index

::: {.callout-note appearance="minimal"}
Definition. Davies-Bouldin Index:
$$
\text{DB} = \frac{1}{K}\sum_{k=1}^{K}\max_{l\neq k}\frac{\bar{d}_k+\bar{d}_l}{d(k,l)}.
$$ {#eq-davies-bouldin}
:::

Lower DB values indicate superior cluster compactness and separation [@davies1979].

### Calinski-Harabasz Index

::: {.callout-note appearance="minimal"}
Definition. Calinski-Harabasz Index:
$$
\text{CH} = \frac{\text{SS}_B/(K-1)}{\text{SS}_W/(n-K)}.
$$ {#eq-calinski-harabasz}
:::

Higher CH values denote distinct, dense cluster separations [@calinski1974].

```{python}
from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, davies_bouldin_score, calinski_harabasz_score

X, y_true = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)

for k in range(2, 6):
    km = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = km.fit_predict(X)
    s = silhouette_score(X, labels)
    db = davies_bouldin_score(X, labels)
    ch = calinski_harabasz_score(X, labels)
    print(f"k={k} | Silhouette: {s:.3f} | Davies-Bouldin: {db:.3f} | Calinski-Harabasz: {ch:.1f}")
```

Unsupervised clustering organizes unlabeled data using geometric or probabilistic distance metrics.
