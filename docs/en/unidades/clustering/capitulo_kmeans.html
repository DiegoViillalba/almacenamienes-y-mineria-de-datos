K-Means is the most widely deployed clustering algorithm due to its conceptual simplicity, linear computational scaling per iteration, and interpretable mean-centroid cluster representations (MacQueen 1967; Lloyd 1982).

1 K-Means Objective Function

K-Means partitions \(n\) instances into \(k\) clusters \(C_1,\dots,C_k\) minimizing within-cluster sum-of-squares (WCSS):

Definition. K-Means WCSS Objective: \[ J(C_1,\dots,C_k) = \sum_{j=1}^{k}\sum_{\mathbf{x}\in C_j}\|\mathbf{x}-\boldsymbol{\mu}_j\|^2, \tag{1}\] where \(\boldsymbol{\mu}_j = \frac{1}{|C_j|}\sum_{\mathbf{x}\in C_j}\mathbf{x}\) denotes the centroid vector of cluster \(j\).

2 Lloyd’s Algorithm

Lloyd’s K-Means Algorithm: 1. Initialize: Select \(k\) initial centroids \(\boldsymbol{\mu}_1,\dots,\boldsymbol{\mu}_k\). 2. Assignment Step: Assign each instance \(\mathbf{x}_i\) to nearest centroid: \[\ell(i) = \arg\min_{j} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2\] 3. Update Step: Recompute centroids as mean of assigned points: \[\boldsymbol{\mu}_j = \frac{1}{|C_j|}\sum_{\ell(i)=j}\mathbf{x}_i\] 4. Convergence: Repeat steps 2-3 until cluster assignments stabilize.

3 K-Means++ Initialization

Standard random initialization is vulnerable to suboptimal local minima. K-Means++ (Arthur and Vassilvitskii 2007) selects initial centroids using distance-proportional sampling \(P(\mathbf{x}_i) \propto D(\mathbf{x}_i)^2\), bounding expected WCSS within \(O(\log k)\) of global optimum.

4 K-Medoids (PAM)

K-Medoids represents clusters using actual exemplar data points (medoids) rather than spatial means, offering robustness against outliers (Kaufman and Rousseeuw 1990).

Definition. Medoid Selection: \[ \mathbf{m}_j = \arg\min_{\mathbf{x}\in C_j}\sum_{\mathbf{x}'\in C_j}d(\mathbf{x},\mathbf{x}'). \tag{2}\]

from sklearn.datasets import make_blobs
from sklearn.cluster import KMeans

X, _ = make_blobs(n_samples=300, centers=4, cluster_std=0.7, random_state=7)

wcss = []
for k in range(1, 7):
    km = KMeans(n_clusters=k, random_state=0, n_init=10)
    km.fit(X)
    wcss.append(km.inertia_)
    print(f"k={k} | WCSS: {km.inertia_:.2f}")

5 Summary

K-Means partitions vector spaces by minimizing squared Euclidean distance from centroids. K-Means++ mitigates initialization sensitivity, while K-Medoids replaces cluster means with actual medoid observations to improve outlier robustness (MacQueen 1967; Arthur and Vassilvitskii 2007; Kaufman and Rousseeuw 1990).

K-Means is the most widely deployed clustering algorithm due to its conceptual simplicity, linear computational scaling per iteration, and interpretable mean-centroid cluster representations [@macqueen1967; @lloyd1982].

## K-Means Objective Function

K-Means partitions $n$ instances into $k$ clusters $C_1,\dots,C_k$ minimizing within-cluster sum-of-squares (WCSS):

::: {.callout-note appearance="minimal"}
Definition. K-Means WCSS Objective:
$$
J(C_1,\dots,C_k) = \sum_{j=1}^{k}\sum_{\mathbf{x}\in C_j}\|\mathbf{x}-\boldsymbol{\mu}_j\|^2,
$$ {#eq-kmeans-obj}
where $\boldsymbol{\mu}_j = \frac{1}{|C_j|}\sum_{\mathbf{x}\in C_j}\mathbf{x}$ denotes the centroid vector of cluster $j$.
:::

## Lloyd's Algorithm

::: {.callout-note appearance="minimal"}
**Lloyd's K-Means Algorithm:**
1. **Initialize:** Select $k$ initial centroids $\boldsymbol{\mu}_1,\dots,\boldsymbol{\mu}_k$.
2. **Assignment Step:** Assign each instance $\mathbf{x}_i$ to nearest centroid:
   $$\ell(i) = \arg\min_{j} \|\mathbf{x}_i - \boldsymbol{\mu}_j\|^2$$
3. **Update Step:** Recompute centroids as mean of assigned points:
   $$\boldsymbol{\mu}_j = \frac{1}{|C_j|}\sum_{\ell(i)=j}\mathbf{x}_i$$
4. **Convergence:** Repeat steps 2-3 until cluster assignments stabilize.
:::

## K-Means++ Initialization

Standard random initialization is vulnerable to suboptimal local minima. K-Means++ [@arthur2007] selects initial centroids using distance-proportional sampling $P(\mathbf{x}_i) \propto D(\mathbf{x}_i)^2$, bounding expected WCSS within $O(\log k)$ of global optimum.

  const PAD={l:44,r:16,t:20,b:30};
  const CW=W-PAD.l-PAD.r,CH=H-PAD.t-PAD.b;

  let k=3,cents=[],labels=[],phase='init',iter=0,converged=false;
  function dist2(a,b){return(a[0]-b[0])**2+(a[1]-b[1])**2;}

  function initCents(k){
    const idx=[];
    while(idx.length<k){const r=Math.floor(Math.random()*SEED.length);if(!idx.includes(r))idx.push(r);}
    return idx.map(i=>[...SEED[i]]);
