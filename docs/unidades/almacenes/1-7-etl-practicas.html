14  Prácticas ETL en Databricks

Este capítulo contiene los ejercicios de aplicación. Todos se ejecutan en Databricks Community Edition usando el clúster configurado en el primer capítulo del bloque.

Tip

Workflow sugerido por ejercicio: 1. Crear un notebook nuevo en Databricks con el nombre del ejercicio. 2. En la primera celda: # Ejercicio E-X — Título 3. Ejecutar celda por celda, observar el Spark UI para ver el plan de ejecución. 4. Adjuntar capturas del resultado como evidencia.

14.1 1. Ejercicios

14.1.1 1.1 Ejercicio E-3 — Pipeline incremental con Delta Lake

Importante

Ejercicio E-3: Carga incremental

Simula un pipeline de producción que carga datos mes a mes sin duplicar registros.

from pyspark.sql import SparkSession
from delta import DeltaTable, configure_spark_with_delta_pip

spark = configure_spark_with_delta_pip(
    SparkSession.builder.appName("E3-Incremental")
    .config("spark.sql.extensions",
            "io.delta.sql.DeltaSparkSessionExtension")
    .config("spark.sql.catalog.spark_catalog",
            "org.apache.spark.sql.delta.catalog.DeltaCatalog")
    .master("local[*]")
).getOrCreate()

DELTA_PATH = "output/delta_taxi/"
MESES = [
    "data/yellow_tripdata_2023-01.parquet",
    "data/yellow_tripdata_2023-02.parquet",
    "data/yellow_tripdata_2023-03.parquet",
]

def transform(df):
    from pyspark.sql.functions import col, hour, dayofweek, month
    return (df
        .filter(col("trip_distance") > 0)
        .filter(col("fare_amount").between(2.5, 500))
        .withColumn("hora", hour("tpep_pickup_datetime"))
        .withColumn("mes",  month("tpep_pickup_datetime"))
    )

for path in MESES:
    nuevos = transform(spark.read.parquet(path))

    if DeltaTable.isDeltaTable(spark, DELTA_PATH):
        # UPSERT: insertar solo lo que no existe
        dt = DeltaTable.forPath(spark, DELTA_PATH)
        (dt.alias("viejo")
           .merge(nuevos.alias("nuevo"),
                  "viejo.VendorID = nuevo.VendorID AND "
                  "viejo.tpep_pickup_datetime = nuevo.tpep_pickup_datetime")
           .whenNotMatchedInsertAll()
           .execute())
    else:
        # Primera carga
        nuevos.write.format("delta").mode("overwrite").save(DELTA_PATH)

    print(f"✅ {path.split('/')[-1]} cargado. Total filas: "
          f"{spark.read.format('delta').load(DELTA_PATH).count():,}")

spark.stop()

Preguntas: a) ¿Qué pasa si cargas el mismo mes dos veces? ¿Por qué? b) Modifica el MERGE para que si un viaje ya existe pero tiene distinto total_amount, actualice el registro (simula una corrección tardía). c) Usa DESCRIBE HISTORY delta.\output/delta_taxi/`` para ver el log de transacciones.

14.1.3 1.3 Ejercicio E-5 — Detección de calidad con Great Expectations

Importante

Ejercicio E-5: Validación automatizada

pip install great_expectations
import great_expectations as gx
from great_expectations.dataset import SparkDFDataset

spark = SparkSession.builder.appName("E5-GX").master("local[*]").getOrCreate()
df = spark.read.parquet("data/yellow_tripdata_2023-01.parquet")

# Convertir a Great Expectations dataset
gx_df = SparkDFDataset(df)

# Definir expectativas de calidad
resultados = []
resultados.append(gx_df.expect_column_values_to_not_be_null("tpep_pickup_datetime"))
resultados.append(gx_df.expect_column_values_to_be_between(
    "trip_distance", min_value=0, max_value=500))
resultados.append(gx_df.expect_column_values_to_be_between(
    "fare_amount", min_value=0, max_value=1000))
resultados.append(gx_df.expect_column_values_to_be_in_set(
    "payment_type", [1, 2, 3, 4, 5, 6]))
resultados.append(gx_df.expect_column_values_to_not_be_null("VendorID"))

# Reporte
for r in resultados:
    icon = "✅" if r["success"] else "❌"
    print(f"{icon} {r['expectation_config']['expectation_type']} "
          f"({r['expectation_config']['kwargs'].get('column','')}) "
          f"— {r['result'].get('unexpected_percent',0):.2f}% inesperado")

spark.stop()

Preguntas: a) ¿Qué expectativas fallan? ¿Cómo lo interpretarías en un pipeline real? b) Agrega una expectativa para verificar que passenger_count nunca supere 6. c) ¿Dónde colocarías estas validaciones en el pipeline E→T→L?
