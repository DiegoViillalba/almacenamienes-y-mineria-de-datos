1 Introducción

La concentración estudia cómo se reparte una masa no negativa —ventas, ingreso, consumo o participación— entre unidades. Puede existir una media estable y, aun así, depender el total de unas pocas categorías o establecimientos.

Definición. Si \(s_i=x_i/\sum_jx_j\) es la participación de la unidad \(i\), una distribución está más concentrada cuando pocas participaciones reúnen gran parte del total.

2 Razones de concentración

Ordenando \(s_{(1)}\ge\cdots\ge s_{(K)}\), la razón de concentración de las \(k\) unidades principales es

\[ CR_k=\sum_{i=1}^{k}s_{(i)}. \tag{1} \]

\(CR_k\) comunica con claridad cuánto aporta el top k, aunque ignora cómo se distribuye la masa dentro y fuera de ese grupo.

3 Índice Herfindahl–Hirschman

\[ HHI=\sum_{i=1}^{K}s_i^2. \tag{2} \]

El índice vale \(1/K\) bajo reparto uniforme y 1 bajo concentración total. A veces se reporta en escala 0–10,000 multiplicando por 10,000 (Hirschman 1945). Para comparar distintos \(K\) puede normalizarse:

\[ HHI^*=\frac{HHI-1/K}{1-1/K}. \tag{3} \]

4 Curva de Lorenz

Ordenando \(x_{(1)}\le\cdots\le x_{(n)}\), la curva de Lorenz relaciona la fracción acumulada de unidades con la fracción acumulada de masa (Lorenz 1905):

\[ L_i=\frac{\sum_{j=1}^{i}x_{(j)}}{\sum_{j=1}^{n}x_{(j)}}. \tag{4} \]

5 Coeficiente de Gini

El coeficiente de Gini es dos veces el área entre la diagonal de igualdad y la curva de Lorenz (Gini 1912). Para observaciones no negativas ordenadas:

\[ G=\frac{2\sum_{i=1}^{n}i x_{(i)}}{n\sum_{i=1}^{n}x_{(i)}}-\frac{n+1}{n}. \tag{5} \]

Esta fórmula requiere masa no negativa y total positivo. El coeficiente de Gini de desigualdad no es la impureza de Gini usada para diversidad o árboles de decisión.

6 Cálculo manual paso a paso

Supongamos cuatro outlets con ventas

\[ x=(10,20,30,40). \]

6.1 Participaciones y razón de concentración

Paso 1. Calcular el total:

\[ T=10+20+30+40=100. \]

Paso 2. Dividir cada venta entre el total:

\[ s_1=\frac{10}{100}=0.10,\quad s_2=\frac{20}{100}=0.20,\quad s_3=\frac{30}{100}=0.30,\quad s_4=\frac{40}{100}=0.40. \]

Paso 3. Ordenar las participaciones de mayor a menor:

\[ (0.40,0.30,0.20,0.10). \]

Paso 4. Sumar las dos mayores:

\[ CR_2=0.40+0.30=0.70=70\%. \]

Los dos outlets principales aportan 70% de las ventas.

6.2 HHI y HHI normalizado

Paso 1. Elevar cada participación al cuadrado:

\[ 0.10^2=0.01,\quad0.20^2=0.04,\quad 0.30^2=0.09,\quad0.40^2=0.16. \]

Paso 2. Sumar:

\[ HHI=0.01+0.04+0.09+0.16=0.30. \]

En escala 0–10,000:

\[ HHI_{10000}=0.30(10000)=3000. \]

Paso 3. Normalizar considerando \(K=4\):

\[ HHI^*=\frac{HHI-1/K}{1-1/K} =\frac{0.30-1/4}{1-1/4} =\frac{0.30-0.25}{0.75} =\frac{0.05}{0.75}=0.0667. \]

6.3 Puntos de la curva de Lorenz

Los valores ya están ordenados de menor a mayor.

La fracción acumulada de unidades avanza en cuartos:

\[ u=(0,0.25,0.50,0.75,1.00). \]

Acumulamos las ventas y dividimos entre 100:

\[ L_0=0, \]

\[ L_1=\frac{10}{100}=0.10, \]

\[ L_2=\frac{10+20}{100}=\frac{30}{100}=0.30, \]

\[ L_3=\frac{10+20+30}{100}=\frac{60}{100}=0.60, \]

\[ L_4=\frac{10+20+30+40}{100}=1.00. \]

Los puntos de Lorenz son

\[ (0,0),\ (0.25,0.10),\ (0.50,0.30),\ (0.75,0.60),\ (1,1). \]

6.4 Coeficiente de Gini

Paso 1. Multiplicar cada valor ordenado por su posición:

\[ 1(10)=10,\quad2(20)=40,\quad3(30)=90,\quad4(40)=160. \]

Paso 2. Sumar los productos:

\[ \sum_{i=1}^{4}i x_{(i)}=10+40+90+160=300. \]

Paso 3. Sustituir \(n=4\) y \(\sum x_i=100\):

\[ G=\frac{2(300)}{4(100)}-\frac{4+1}{4}. \]

Paso 4. Resolver ambas fracciones:

\[ G=\frac{600}{400}-\frac54=1.50-1.25=0.25. \]

El valor 0.25 expresa desigualdad moderada en este ejemplo; no significa que “25% de las unidades concentre las ventas”.

Del cálculo al programa. Validar primero que \(x_i\ge0\) y que la suma sea positiva. Después: normalizar para obtener participaciones, ordenar descendentemente para \(CR_k\), elevar y sumar para HHI, ordenar ascendentemente y acumular para Lorenz, y reutilizar ese orden para Gini.

7 Pareto y participación acumulada

Mostrar código 
import numpy as np
import pandas as pd
import plotly.graph_objects as go
import plotly.express as px
from plotly.subplots import make_subplots

rng = np.random.default_rng(77)
ventas = rng.lognormal(mean=3.5, sigma=1.1, size=35)
tabla = pd.DataFrame({"Unidad": [f"U{i:02d}" for i in range(1, 36)], "Ventas": ventas})
tabla = tabla.sort_values("Ventas", ascending=False)
tabla["Participación acumulada"] = tabla["Ventas"].cumsum()/tabla["Ventas"].sum()

fig = make_subplots(specs=[[{"secondary_y": True}]])
fig.add_bar(x=tabla["Unidad"], y=tabla["Ventas"], name="Ventas", secondary_y=False)
fig.add_scatter(x=tabla["Unidad"], y=tabla["Participación acumulada"],
                mode="lines+markers", name="Participación acumulada", secondary_y=True)
fig.add_hline(y=.80, line_dash="dash", line_color="#D62728", secondary_y=True,
              annotation_text="80%")
fig.update_yaxes(title_text="Ventas", secondary_y=False)
fig.update_yaxes(title_text="Participación acumulada", tickformat=".0%", secondary_y=True)
fig.update_layout(title="Diagrama de Pareto interactivo")
fig.show()

8 Lorenz y Gini

Mostrar código 
def lorenz_gini(x):
    x = np.asarray(x, dtype=float)
    if np.any(x < 0) or x.sum() <= 0:
        raise ValueError("Se requieren valores no negativos y suma positiva")
    x = np.sort(x)
    n = len(x)
    poblacion = np.arange(n + 1)/n
    masa = np.r_[0, np.cumsum(x)/x.sum()]
    gini = 2*np.sum(np.arange(1, n+1)*x)/(n*x.sum())-(n+1)/n
    return poblacion, masa, gini

escenarios = {
    "Reparto cercano": rng.uniform(.8, 1.2, 600),
    "Concentración media": rng.exponential(1, 600),
    "Concentración alta": rng.lognormal(0, 1.4, 600)
}
fig = go.Figure()
fig.add_trace(go.Scatter(x=[0,1], y=[0,1], mode="lines", name="Igualdad",
                         line=dict(dash="dash", color="gray")))
for nombre, x in escenarios.items():
    u, L, g = lorenz_gini(x)
    fig.add_trace(go.Scatter(x=u, y=L, mode="lines", name=f"{nombre} · G={g:.2f}"))
fig.update_layout(title="Curvas de Lorenz para tres niveles de concentración",
                  xaxis_title="Fracción acumulada de unidades",
                  yaxis_title="Fracción acumulada de masa")
fig.show()

Interpretación. Cuanto más se aleja la curva de la diagonal, mayor es la desigualdad. El hover permite responder preguntas operativas como “¿qué proporción de unidades produce 50% del total?”.

9 Concentración al crecer una unidad dominante

Mostrar código 
filas = []
for dominante in np.linspace(.20, .92, 13):
    resto = (1-dominante)/4
    shares = np.array([dominante] + [resto]*4)
    for i, s in enumerate(shares, 1):
        filas.append({"Dominancia": f"{dominante:.2f}", "Unidad": f"U{i}", "Participación": s})
anim = pd.DataFrame(filas)
fig = px.bar(anim, x="Unidad", y="Participación", color="Unidad",
             animation_frame="Dominancia", range_y=[0,1],
             title="Animación: formación de una estructura concentrada")
fig.update_layout(showlegend=False)
fig.show()

¿Cuánto explica el top 3 o top 5? \(CR_k\)
¿Qué tan concentradas están todas las participaciones? HHI / HHI normalizado
¿Cómo se acumula el total? Pareto o Lorenz
¿Cuál es la desigualdad global? Gini

```{python}
}
fig = go.Figure()
fig.add_trace(go.Scatter(x=[0,1], y=[0,1], mode="lines", name="Igualdad",
                         line=dict(dash="dash", color="gray")))
for nombre, x in escenarios.items():
    u, L, g = lorenz_gini(x)
    fig.add_trace(go.Scatter(x=u, y=L, mode="lines", name=f"{nombre} · G={g:.2f}"))
fig.update_layout(title="Curvas de Lorenz para tres niveles de concentración",
                  xaxis_title="Fracción acumulada de unidades",
                  yaxis_title="Fracción acumulada de masa")
fig.show()
```

::: {.callout-important appearance="minimal"}
**Interpretación.** Cuanto más se aleja la curva de la diagonal, mayor es la desigualdad. El hover permite responder preguntas operativas como “¿qué proporción de unidades produce 50% del total?”.
:::

## Concentración al crecer una unidad dominante

```{python}
filas = []
for dominante in np.linspace(.20, .92, 13):
    resto = (1-dominante)/4
    shares = np.array([dominante] + [resto]*4)
    for i, s in enumerate(shares, 1):
        filas.append({"Dominancia": f"{dominante:.2f}", "Unidad": f"U{i}", "Participación": s})
anim = pd.DataFrame(filas)
fig = px.bar(anim, x="Unidad", y="Participación", color="Unidad",
             animation_frame="Dominancia", range_y=[0,1],
             title="Animación: formación de una estructura concentrada")
fig.update_layout(showlegend=False)
fig.show()
```

## Guía de decisión

| Pregunta | Indicador |
|---|---|
| ¿Cuánto explica el top 3 o top 5? | $CR_k$ |
| ¿Qué tan concentradas están todas las participaciones? | HHI / HHI normalizado |
| ¿Cómo se acumula el total? | Pareto o Lorenz |
| ¿Cuál es la desigualdad global? | Gini |
