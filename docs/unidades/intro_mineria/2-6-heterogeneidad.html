1 Introducción

La heterogeneidad pregunta si una población se comporta como una sola unidad o contiene subpoblaciones con composiciones o distribuciones distintas. Conviene separar dos problemas: la diversidad de una variable categórica y las diferencias de una variable numérica entre grupos.

Definición. Hay heterogeneidad cuando la masa se reparte entre diversas categorías o cuando la distribución de una respuesta cambia de forma sistemática entre subgrupos.

2 Diversidad categórica

Sea \(p=(p_1,\ldots,p_K)\) la distribución de proporciones de \(K\) categorías.

2.1 Entropía de Shannon

\[ H(p)=-\sum_{k=1}^{K}p_k\log(p_k). \tag{1} \]

La entropía es cero si una categoría contiene toda la masa y alcanza \(\log K\) bajo uniformidad. Para comparar variables con distinto número de niveles puede usarse

\[ H_{\mathrm{norm}}=\frac{H(p)}{\log K}. \tag{2} \]

La base del logaritmo cambia la unidad, no el orden de las distribuciones (Shannon 1948).

2.2 Índice de Gini–Simpson

\[ D(p)=1-\sum_{k=1}^{K}p_k^2. \tag{3} \]

\(D\) es la probabilidad de que dos observaciones extraídas independientemente pertenezcan a categorías diferentes (Simpson 1949).

El índice Gini–Simpson de diversidad no es el coeficiente de Gini de desigualdad. Aunque ambos usan el apellido Gini, responden preguntas diferentes y poseen fórmulas distintas.

3 Número efectivo de categorías

La transformación \(\exp(H)\) expresa la entropía como el número de categorías igualmente frecuentes que produciría la misma diversidad. Para Gini–Simpson, el equivalente es \(1/\sum p_k^2\). Estas versiones facilitan comparaciones sustantivas.

4 Heterogeneidad de una respuesta entre grupos

Para una respuesta numérica \(Y\) y grupos \(g=1,\ldots,G\), la variación total puede descomponerse en componentes dentro y entre grupos:

\[ SS_T=\sum_i(y_i-\bar y)^2=SS_B+SS_W. \tag{4} \]

Una medida descriptiva del tamaño de las diferencias es

\[ \eta^2=\frac{SS_B}{SS_T}. \tag{5} \]

Valores próximos a cero indican que las medias grupales explican poca variación; valores mayores señalan separación entre grupos.

\(\eta^2\) describe separación de medias, pero no reemplaza la inspección de medianas, dispersión, tamaños de grupo y forma. Tampoco establece causalidad.

5 Cálculo manual paso a paso

5.1 Entropía, Gini–Simpson y categorías efectivas

Supongamos seis observaciones categóricas:

\[ (A,A,A,B,C,C). \]

Paso 1. Contar cada categoría:

\[ f_A=3,\qquad f_B=1,\qquad f_C=2,\qquad n=6. \]

Paso 2. Convertir conteos a proporciones:

\[ p_A=\frac{3}{6}=0.5,\qquad p_B=\frac{1}{6}=0.1667,\qquad p_C=\frac{2}{6}=0.3333. \]

Comprobación:

\[ 0.5+0.1667+0.3333\approx1. \]

Paso 3. Calcular cada término de Shannon usando logaritmo natural:

\[ p_A\ln p_A=0.5\ln(0.5)=0.5(-0.6931)=-0.3466, \]

\[ p_B\ln p_B=0.1667\ln(0.1667)=0.1667(-1.7918)=-0.2986, \]

\[ p_C\ln p_C=0.3333\ln(0.3333)=0.3333(-1.0986)=-0.3662. \]

Paso 4. Sumar y cambiar el signo:

\[ H=-[-0.3466-0.2986-0.3662]=1.0114. \]

Paso 5. Normalizar entre el máximo \(\ln K=\ln3=1.0986\):

\[ H_{\mathrm{norm}}=\frac{1.0114}{1.0986}=0.9206. \]

Para Gini–Simpson elevamos cada proporción al cuadrado:

\[ p_A^2=0.5^2=0.25, \]

\[ p_B^2=\left(\frac16\right)^2=\frac1{36}=0.0278, \]

\[ p_C^2=\left(\frac13\right)^2=\frac1{9}=0.1111. \]

Sumamos y restamos de uno:

\[ D=1-(0.25+0.0278+0.1111)=1-0.3889=0.6111. \]

El número efectivo basado en Shannon es

\[ K_{\mathrm{ef}}=e^H=e^{1.0114}=2.75. \]

La composición observada equivale, aproximadamente, a 2.75 categorías igualmente frecuentes.

5.2 Descomposición entre y dentro de grupos

Ahora consideremos una respuesta numérica dividida en tres grupos:

\[ A=(4,5),\qquad B=(8,9),\qquad C=(5,5). \]

Paso 1. Calcular la media global:

\[ \bar{y}=\frac{4+5+8+9+5+5}{6}=\frac{36}{6}=6. \]

Paso 2. Calcular las medias de grupo:

\[ \bar{y}_A=\frac{4+5}{2}=4.5, \]

\[ \bar{y}_B=\frac{8+9}{2}=8.5, \]

\[ \bar{y}_C=\frac{5+5}{2}=5. \]

Paso 3. Calcular la suma de cuadrados total:

\[ SS_T=(4-6)^2+(5-6)^2+(8-6)^2+(9-6)^2+(5-6)^2+(5-6)^2, \]

\[ SS_T=4+1+4+9+1+1=20. \]

Paso 4. Calcular la variación entre grupos:

\[ SS_B=2(4.5-6)^2+2(8.5-6)^2+2(5-6)^2, \]

\[ SS_B=2(2.25)+2(6.25)+2(1)=4.5+12.5+2=19. \]

El factor 2 aparece porque cada grupo contiene dos observaciones.

Paso 5. Obtener la variación dentro de grupos:

\[ SS_W=SS_T-SS_B=20-19=1. \]

Se puede comprobar directamente:

\[ SS_W=[(4-4.5)^2+(5-4.5)^2] +[(8-8.5)^2+(9-8.5)^2] +[(5-5)^2+(5-5)^2], \]

\[ SS_W=(0.25+0.25)+(0.25+0.25)+(0+0)=1. \]

Paso 6. Calcular eta cuadrada:

\[ \eta^2=\frac{SS_B}{SS_T}=\frac{19}{20}=0.95. \]

En este ejemplo artificial, 95% de la variación total corresponde a diferencias entre las medias grupales.

Del cálculo al programa. Para diversidad: contar categorías, dividir entre \(n\) y acumular \(-p_k\log p_k\) y \(p_k^2\). Para heterogeneidad grupal: calcular la media global, las medias y tamaños de cada grupo, acumular \(SS_T\) y \(SS_B\), y obtener \(\eta^2=SS_B/SS_T\).

import numpy as np
import pandas as pd
import plotly.express as px

escenarios = {
    "Dominante": [0.82, 0.08, 0.06, 0.04],
    "Intermedio": [0.50, 0.25, 0.15, 0.10],
    "Uniforme": [0.25, 0.25, 0.25, 0.25]
}
filas = []
for nombre, probs in escenarios.items():
    for categoria, p in zip(list("ABCD"), probs):
        filas.append({"Escenario": nombre, "Categoría": categoria, "Proporción": p})
div = pd.DataFrame(filas)
fig = px.bar(div, x="Categoría", y="Proporción", color="Categoría",
             animation_frame="Escenario", range_y=[0, 1],
             title="Animación: de dominancia a diversidad categórica")
fig.update_layout(showlegend=False)
fig.show()
Mostrar código 
resumen = []
for nombre, probs in escenarios.items():
    p = np.asarray(probs)
    h = -(p[p>0]*np.log(p[p>0])).sum()
    resumen.append({"Escenario": nombre, "Entropía normalizada": h/np.log(len(p)),
                    "Gini–Simpson": 1-(p**2).sum(), "Categorías efectivas": np.exp(h)})
pd.DataFrame(resumen).round(3)

7 Diferencias entre grupos

Mostrar código 
rng = np.random.default_rng(17)
n = 350
grupos = pd.DataFrame({
    "valor": np.r_[rng.normal(50, 8, n), rng.normal(62, 8, n), rng.normal(75, 14, n)],
    "grupo": ["A"]*n + ["B"]*n + ["C"]*n
})
fig = px.violin(grupos, x="grupo", y="valor", color="grupo", box=True, points="outliers",
                title="Centro, dispersión y forma pueden cambiar entre grupos")
fig.update_layout(showlegend=False)
fig.show()

media_global = grupos["valor"].mean()
ss_total = ((grupos["valor"]-media_global)**2).sum()
medias = grupos.groupby("grupo")["valor"].transform("mean")
ss_entre = ((medias-media_global)**2).sum()
print(f"Eta cuadrada descriptiva: {ss_entre/ss_total:.3f}")

8 Heterogeneidad cruzada

Cuando dos variables categóricas interactúan, una tabla de una sola dimensión puede ocultar combinaciones relevantes. Un heatmap de medianas o medias, acompañado por el conteo de cada celda, ayuda a diferenciar patrones reales de celdas pequeñas.

Comparar únicamente medias grupales puede confundir heterogeneidad con desbalance muestral. Reporte siempre \(n_g\) y revise faltantes estructurales.

¿Cambian las ventas entre grupos? Resúmenes por grupo, violin/boxplot, \(\eta^2\)

```{python}
escenarios = {

        filas.append({"Escenario": nombre, "Categoría": categoria, "Proporción": p})
div = pd.DataFrame(filas)
fig = px.bar(div, x="Categoría", y="Proporción", color="Categoría",
             animation_frame="Escenario", range_y=[0, 1],
             title="Animación: de dominancia a diversidad categórica")
fig.update_layout(showlegend=False)
fig.show()
```

```{python}
resumen = []
for nombre, probs in escenarios.items():
    p = np.asarray(probs)
    h = -(p[p>0]*np.log(p[p>0])).sum()
    resumen.append({"Escenario": nombre, "Entropía normalizada": h/np.log(len(p)),
                    "Gini–Simpson": 1-(p**2).sum(), "Categorías efectivas": np.exp(h)})
pd.DataFrame(resumen).round(3)
```

## Diferencias entre grupos

```{python}
rng = np.random.default_rng(17)
n = 350
grupos = pd.DataFrame({
    "valor": np.r_[rng.normal(50, 8, n), rng.normal(62, 8, n), rng.normal(75, 14, n)],
    "grupo": ["A"]*n + ["B"]*n + ["C"]*n
})
fig = px.violin(grupos, x="grupo", y="valor", color="grupo", box=True, points="outliers",
                title="Centro, dispersión y forma pueden cambiar entre grupos")
fig.update_layout(showlegend=False)
fig.show()

media_global = grupos["valor"].mean()
ss_total = ((grupos["valor"]-media_global)**2).sum()
medias = grupos.groupby("grupo")["valor"].transform("mean")
ss_entre = ((medias-media_global)**2).sum()
print(f"Eta cuadrada descriptiva: {ss_entre/ss_total:.3f}")
```

## Heterogeneidad cruzada

Cuando dos variables categóricas interactúan, una tabla de una sola dimensión puede ocultar combinaciones relevantes. Un heatmap de medianas o medias, acompañado por el conteo de cada celda, ayuda a diferenciar patrones reales de celdas pequeñas.

::: {.callout-warning appearance="minimal"}
Comparar únicamente medias grupales puede confundir heterogeneidad con desbalance muestral. Reporte siempre $n_g$ y revise faltantes estructurales.
:::

## Guía de decisión

| Pregunta | Medida o gráfica |
|---|---|
| ¿Qué tan diversa es una categoría? | Entropía, Gini–Simpson, barras |
| ¿Cuántas categorías efectivas hay? | $\exp(H)$ o inverso de Simpson |
| ¿Cambian las ventas entre grupos? | Resúmenes por grupo, violin/boxplot, $\eta^2$ |
| ¿Hay interacción entre dos grupos? | Heatmap con tamaños de celda |
